# Adaptive Cognitive Budgeting (ACB) Demo

This Hugging Face Space demonstrates **Adaptive Cognitive Budgeting (ACB)** for GPU-Free LLMs.
It dynamically allocates Context Window and CPU Threads based on query complexity and available host memory.

See the [GitHub Repository](https://github.com/SaiDheeraj-19/Adaptive-Cognitive-Budgeting-GPU-Free-LLMs) for the full code and paper.
